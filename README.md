# SISGEM-CC

Sistema de Gestión Municipal Cuatro Cañadas.

Portal digital para iniciar trámites, consultar servicios y realizar el seguimiento de solicitudes del Gobierno Autónomo Municipal de Cuatro Cañadas.

## Desarrollo

1. Instala las dependencias con `pnpm install`.
2. Inicia el proyecto con `pnpm dev`.
3. Abre `http://localhost:3000`.

## Publicación

El proyecto está preparado para conectarse a GitHub y desplegarse en Vercel como una aplicación Next.js.

Configura `NEXT_PUBLIC_SITE_URL` con la dirección definitiva del sitio para que las vistas previas compartidas usen la URL correcta.
